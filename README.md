# 🍌 Nano Banana Lab

Google Gemini の画像生成モデル **Nano Banana**（Gemini Image系）を試すための実験用ローカルサイトです。

## 機能

- **入力画像 / リファレンス画像 / プロンプト** をそれぞれライブラリに保存（ブラウザの IndexedDB に永続化、再利用可能）
- プロンプト内で添付画像を参照する**シンタックス** `@in1` `@ref1` …（チップをクリックでカーソル位置に挿入）
- API準拠の設定: **アスペクト比 / 出力枚数(1〜8) / モデル選択（Nano Banana 2 / Nano Banana Pro）**
- 生成ごとの**概算コスト(USD)** と**所要時間**を表示（累計コストもヘッダーに表示）
- 生成結果を画面に一覧表示。各結果は**ワンクリックで入力画像として再利用**可能
- 1バッチ分の結果を**Zipで一括ダウンロード**（メタデータJSON同梱）

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

### APIキー（サイト上で設定）

初回アクセス時に設定モーダルが開きます。[Google AI Studio](https://aistudio.google.com/apikey) で取得したキーを入力し「保存して有効化」を押すだけです（右上の **⚙ APIキー** からいつでも変更可）。

- キーは**ブラウザのlocalStorageにのみ保存**され、サーバーには保存されません。
- 生成時にリクエストヘッダ `x-gemini-api-key` で送信され、サーバーのAPIルートからGoogleへ中継されます。
- 「接続テスト」で課金の発生しないモデル一覧エンドポイントを使ってキーの有効性を確認できます。

> サーバー側に共有キーを置きたい場合は環境変数 `GEMINI_API_KEY` を設定すれば、ユーザーがキー未設定でもそれがフォールバックとして使われます（Vercelの個人利用などでは未設定のままでOK）。

## モデルIDについて

`lib/pricing.ts` でモデルID・概算単価・対応アスペクト比を定義しています。Gemini API のモデルIDや料金は変わる可能性があるため、必要に応じて編集するか、環境変数で上書きできます:

```bash
NANO_BANANA_2_MODEL_ID=gemini-2.5-flash-image
NANO_BANANA_PRO_MODEL_ID=gemini-3-pro-image-preview
```

> ⚠️ 表示されるコストは公開情報を基にした**概算**です。実際の請求額は Google Cloud / AI Studio の明細をご確認ください。

## 使い方

1. 左パネルから入力画像・リファレンス画像を登録（ドラッグ&ドロップ可）
2. 使いたい画像をクリックして選択（`@in1`, `@ref1` … の番号が振られる）
3. プロンプトを入力。チップをクリックすると `@in1` 等をプロンプトに挿入できる
4. モデル・アスペクト比・枚数を設定して「✨ 生成する」
5. 結果はバッチ単位で下に蓄積。各画像は「入力に使う」で再利用、「Zip一括DL」でまとめて保存

## 技術スタック

Next.js (App Router) / React 19 / TypeScript / Tailwind CSS v4 / @google/genai / JSZip

データはすべてブラウザローカル（IndexedDB）に保存され、APIキーはサーバー側（APIルート）でのみ使用されます。
